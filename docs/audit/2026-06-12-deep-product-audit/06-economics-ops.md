# Фаза 7. Economics, ops, deploy readiness

Дата: 2026-06-12  
Статус: обязательные проверки зелёные. Для публичного платного запуска есть launch blockers уровня операционной готовности.

## Итог

Экономика, деплой и recovery-семантика уже существенно сильнее типичного MVP: пакеты Start/Pro/Agency публичны, Scale скрыт; `audit-economics` есть в CI; Fly разделяет `web` и `worker`; Prisma migrations идут через release command; CI поднимает Postgres/Redis и проверяет migration drift; Postgres queue использует leases, heartbeats и retry; usage/payment/audit таблицы присутствуют.

Но продукт пока нельзя назвать "лучшим" операционно: `ECON_SUPPORT_RESERVE_RUB` задокументирован и требуется в production, но фактически не участвует в `audit-economics`; нет проверенного backup/restore/rollback runbook; нет finance export/dashboard для сверки денег, кредитов и провайдерских расходов; alerting/runbooks для provider outages и failed payments пока описаны недостаточно.

## Вывод по фазе

Для beta/controlled launch в Stars-only конфигурации продукт близок: build/test/deploy path зелёный, jobs/retries/retention продуманы, экономика по текущей модели проходит. Для честного публичного платного запуска нужно сначала закрыть P1 blockers: support-reserve semantics, backup/restore drill, finance reconciliation и alerting. Без этого продукт может работать, но "лучшим" его назвать нельзя.
