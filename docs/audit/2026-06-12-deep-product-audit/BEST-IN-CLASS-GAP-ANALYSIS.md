## Best-in-class threshold

Чтобы честно назвать продукт лучшим в классе, нужен минимум:

1. P1 blockers закрыты и повторно проверены в CI/staging.
2. Current local code задеплоен, а Fly production повторно прошёл golden/live eval.
3. Есть operational proof: backup restore drill, finance reconciliation, alerts, provider smoke pack.
4. UX polish закрыт для RU-first Mini App и payment failure flows.
5. Security/privacy audit trail покрывает OSINT/photo/admin/delete-me сценарии тестами и логами.
